# VisionEvidence-Agent

A Lightweight Multimodal Evidence-Grounded Agent for Research and Evaluation.

## Overview

VisionEvidence-Agent is a research-oriented project exploring multimodal claim understanding, evidence retrieval, and tool-assisted verification.

The project aims to build a reproducible experimental framework rather than only an application demo.

## Planned Features

- Visual claim understanding with a vision-language model
- BM25, dense, and hybrid evidence retrieval
- Lightweight agent-based tool selection
- Evidence-grounded claim verification
- Reproducible evaluation and ablation experiments

## Technology Stack

Python, PyTorch, Transformers, FAISS, and Gradio.

## Project Status

Planning and environment setup.

## Reproducibility

Environment configuration, evaluation protocols, and experiment results will be documented as development progresses.
