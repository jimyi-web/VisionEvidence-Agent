## 查询与 BM25 检查

已验证：查询由 objects、visible_text 固定拼接；uncertainties 排除。实体/状态总体保留，关键遗漏集中在 S04 的编号与 S08 全空。S03 的 empty、S01/S02/S05 的 beside、S09 的 under 等状态/关系未进入结构查询。Sunday 在 S03 保留，S07 中文周日在字段中保留但无法分词；没有其他具体日期、命名城市或真实事件身份可据以判断丢失。场所类别 library entrance、river bridge 等保留；S04 丢失的是具体站台编号。原描述本身没有丰富动作，不能把结构提取解释为已验证的事件理解。

ASCII `[a-z0-9]+` 只保留小写英文词和数字，不做中文切词、翻译、同义词扩展、词干化、停用词过滤或否定推理。S06/S07 的机制由实际 token 与源码共同确认；S09 的通用词匹配由逐词贡献确认。数字本可保留，S04 不是分词器过滤数字。

查询在 BM25 中执行 sorted(set(tokens))：重复 bus/bridge 不额外加权；查询长度没有显式归一化或惩罚，也没有本轮长度截断。长描述影响排序是因为新增的不同词项产生贡献，不是“越长直接扣分”或“重复词抢权重”。文档词频与文档长度归一化确实参与评分；语料外词没有贡献。词袋不保留语序/对象关系，也不理解 No drinking/no bicycle 的否定。

## 推测、限制与下一阶段

已验证的是本合成闭集上的程序行为、文本差异和分数归因。未验证的是这些遗漏在真实 VLM 上发生的概率、人工是否认可全部标签，以及任何改进对真实任务的收益。S04 指标高估语义区分能力是该例的观察，不能估计总体发生率。

可能的改进方向（仅假设，本轮未实现/调参）：独立 dev 集评估保留可见数字、状态、关系的查询表示；同义词与多语言检索；停用词/字段权重或混合检索；冲突与否定感知；空提取的显式诊断及预先定义的独立回退实验条件。每项都可能损失信息或带来新偏差，不承诺改善 Structured。

下一步先由人工填写复核表，明确部分覆盖、额外属性、同义/跨语言、冲突证据及文档重复的判定边界。任何标签修订另存理由和版本，不覆盖 v1，也不据此反向优化 synthetic_test。之后才考虑独立且有来源/授权的 dev 数据与预先固定协议；GPU 验收仍需另行批准。
